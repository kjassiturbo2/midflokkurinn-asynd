# Eignayfirlit

Allar slóðir miðast við rót skillsins. SVG og PNG útgáfur merkjanna hafa sömu grunnheiti. Skrár eru óbreytt afrit; aðeins valin skráarheiti hafa verið samræmd.

| Eign | Slóð | Notkun |
|---|---|---|
| Hestur yfir orðmerki, hvít útgáfa | assets/logos/logo-stacked-white.svg | Dökkur grunnur, lóðrétt merki |
| Hestur yfir orðmerki, blá útgáfa | assets/logos/logo-stacked-blue.svg | Ljós grunnur |
| Hestur við hlið orðmerkis, hvítt | assets/logos/logo-horizontal-white.svg | Lárétt merki á dökku |
| Hestur við hlið orðmerkis, blátt | assets/logos/logo-horizontal-blue.svg | Lárétt merki á ljósu |
| Hvítur hestur, gegnsætt | assets/logos/horse-white.svg | Dökkur grunnur |
| Blár hestur, gegnsætt | assets/logos/horse-blue.svg | Ljós grunnur |
| Blár hestur í hvítum hring | assets/logos/horse-blue-white-circle.svg | Ljós hringflötur |
| Hvítur hestur í bláum hring | assets/logos/horse-white-blue-circle.svg | Dökkur hringflötur |
| xM, gegnsætt | assets/logos/xm-transparent.svg | Gyllt x og hvítt M; dökkur grunnur |
| xM á dökkbláum fleka | assets/logos/xm-panel.svg | Merki með eigin bakgrunni |
| Bakgrunnar | assets/backgrounds/nott.png, eldur.png, mold.png | Upprunalegir glærubakgrunnar |
| Kjördæmis- og sveitarfélagaútgáfur | assets/regional/ | Upprunaleg staðbundin merki, PNG og Vector |
| Samfélagsmiðlaeignir | assets/social/ | Prófílmynd, yfirlag og límmiðar |
| Litaskjal | assets/color-guide.pdf | Opinber litagildi og hlutverk |
| Letur | assets/fonts/ | Roboto og Blacker Pro Display Condensed |
| Stílgildi og vefstílar | assets/tokens.json, assets/brand.css | Endurnýtanleg stafræn gildi |

Íslensk skráarheiti í regional og social geta verið Unicode NFD. Notaðu skráaleit og raunverulegar slóðir í stað þess að giska á stafsetningu eða form hreimstafa.

[assets/manifest.json](../assets/manifest.json) tengir öll afrit við upprunaleg heiti og varðveitir SHA-256 fyrir heilleikaprófun. Ekki endurgera kjördæmismerki með texta þegar rétt útgáfa er þegar til.

Poppins ExtraBold og OFL-leyfi í `assets/fonts/` fylgja valkostinum [veed-texti](veed-texti.md).
